# Резюме — Даниил Вусык

Одностраничное онлайн-резюме. Partner &amp; Payment Operations, iGaming / fintech.

**Открыть:** https://USERNAME.github.io/REPO/

## Как устроено

Один файл — `index.html`. Внутри вся вёрстка, стили и скрипты, внешних зависимостей нет:
ни шрифтов с CDN, ни библиотек, ни картинок. Открывается двойным кликом без интернета.

- адаптивная вёрстка, меню уходит в бургер на ширине до 960px
- отдельные стили для печати: кнопка «Скачать PDF» отдаёт аккуратный A4
- иконка вкладки — инлайновый SVG в `data:`-ссылке
- Open Graph для превью при отправке ссылки в мессенджеры

## Правки

Всё содержимое — прямо в `index.html`:

| Что | Где искать |
|---|---|
| Имя, контакты | блок `<header class="topbar">` и `.hero-name` |
| О себе | секция `id="about"` |
| Опыт работы | секция `id="experience"` |
| Навыки | секция `id="stack"` |
| Образование | секция `id="education"` |
| Цвета | блок `:root` в начале `<style>` |

После правки — коммит в `main`, GitHub Pages обновит сайт сам за минуту.
